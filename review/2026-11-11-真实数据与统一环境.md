# 真实数据复跑与统一环境（v0.4.0）

2026-11-11。结论：**上一轮“暂缓扩建”的前提（经济影响很小）在真实数据上不成立，但 ECRS 对这块电池仍是小头；环境已合并为一套，新功能都保持上界精确；现有因果基线偏弱，是下一步的主要短板。**

## 一、真实数据上的 ECRS 持续时间检验

数据：Grid Status API 的 SCED 逐次运行数据（HB_WEST 的 LMP＋可靠性部署加价 RTRDPA，实时 ECRS MCPC），按“生效价格的时间加权”折算成五分钟价格。不再使用 HybridBid 镜像。模型、电池、策略、参数与 10-26 的首轮完全一致，没有调参。

- 四个 15 分钟/日前数据集重新下载后，校验和与 README 公布值全部一致（另一台机器、两周后的第二次独立复现）。
- 五分钟数据质量：7 月至 10 月 33,408 个时段中，只有个别时段不是“已发布的生效价格”（某次 SCED 运行缺加价或 MCPC）。规则不变：不补不插，含这类时段的面板及其后一个面板（历史不完整）整体跳过并列出。测试段 20 个面板跑了 16 个，验证段 18 个跑了 16 个。
- 五分钟能量价格的 15 分钟均值与官方结算点价格相比：11,127 个时段中 99.99% 相差不超过 1 美分，最大 0.81 美元。

| Central 运行窗口 | 面板 | 0.25h 规划请求被裁剪 | 1h 相对 0.25h oracle 收益 | ECRS 占 1h oracle |
|---|---:|---:|---:|---:|
| 2026-02-02 至 02-04 | 1 | 27.8% | −0.19% | 0.5% |
| 2026-01-24 至 01-26 | 1 | 23.0% | −0.16% | 0.6% |
| 验证段 07-02 至 08-24 | 16 | 21.8% | −2.34% | 3.6% |
| 测试段 08-25 至 10-23（留出） | 16 | 26.3% | −2.73% | 3.8% |

测试段是留出面板：协议在计算任何结果前写入文件，先于验证段运行。需要说明的是，数据检查时看过该区间价格的汇总统计（中位数等），但没有在上面跑过任何策略。

对上一轮四条判断的更新：

1. **“约 18% 的时段不可执行”得到确认且更高**：四个窗口都在 22%–28%。
2. **“经济影响偏弱”需要修正**：留出测试段上，一小时规则让 oracle 收益下降 2.7%（单面板 0.2%–7.7%，中位 2.2%），而镜像数据上是 0.02% 和 0.41%。按 0.25 小时建模会把 ECRS 收入高估约一倍（5.4 万对 2.5 万美元）。冬季两个窗口仍然很小（0.16%–0.19%）。
3. **“一小时规划不一定赚得更多”仍然成立**：一小时规划在验证段胜出、测试段落后，按面板看各赢一半左右。两个规划器都只捕获 oracle 的 3%–7%，差异主要来自预测质量。
4. **ECRS 本身是小头**：夏秋季占 oracle 收益 3.6%–3.8%。实时 ECRS 价格绝大多数时候接近零（中位数 0.05 美元/MW·h），靠少数尖峰。

仍未解决：发布时间延迟仍是假设（SCED 时间戳显示每次运行在时段开始后约 20 秒，价格何时公布没有测到）；保守的仅放电侧模型；现金流代理而非官方结算。1 月、2 月窗口换了枢纽和能量价格定义，不是对镜像结果的同口径复现。

## 二、环境合并与新功能

`RTCBEnv` 现在是唯一的核心环境，所有新选项默认关闭，v0.2 的设置和结果不变（原 191 项测试未改动即通过，除一项“两结算只能单日”的断言按新行为删除）。

| 改进项 | 实现 | 上界是否仍精确 |
|---|---|---|
| 五分钟调度、15 分钟结算 | `dt_hours=1/12, settlement_minutes=15` | 是；测试验证与 15 分钟环境逐步一致 |
| ECRS 进入主环境 | `ecrs_prices`，规则代码与实验模型共用 | 是；测试验证与实验环境逐步一致 |
| 日前 ECRS 头寸＋实时偏差结算 | `da_ecrs_prices`，`DayAheadBid(ecrs_mw=...)` | 是；日前部分按价差单独求解 |
| 部署（中标后被调用） | `ecrs_deployment`，外生输入 | 是；随机部署下终端 SoC 目标仍满足 |
| 报价曲线动作 | `action_mode="offer"` | 是；价格接受型报价可复现任意功率 |
| 日前限价报价（可多段） | `DayAheadBid(energy_limit_price=...)` | 是 |
| 两结算跨日 | `episode_days > 1`，次日日前结果 13:30 才可见 | 是 |

诚实的限制：

- 日前 ECRS 的结算是按 RTC+B 两结算的逻辑写的，没有逐项对照规程第 6.7 节公式。
- 部署只是接口：没有 ERCOT 的实际部署数据，所有结果都没有用到它。
- 报价和限价都是对历史价格出清，电池仍是价格接受者。

## 三、结果要点

数字以 README 的 Results 一节和 `results/` 下各表为准，此处只记判断。v0.2 的全部原有数字在重新下载的数据上逐美元复现。

- **五分钟能量＋ECRS（HB_WEST）**：在保守模型下，ECRS 让上界提高 3%–5%（两市场 3.0%、4.8%；仅实时 3.4%、4.1%）。日前联合计划的收入中 10%（验证段）和 26%（测试段）来自 ECRS。给实时 MPC 加上 ECRS 只多 2%–3%，落在置信区间之内。最好的因果策略只到上界的 28%–33%。
- **首轮实验用的一小时持续性 MPC 在这个设置下亏钱**（−2.8 万、−1.9 万美元）：五分钟调度追逐的价格波动被 15 分钟结算平均掉，还要付退化成本。它不能再当基线。
- **报价曲线基线没有带来收益提升，反而更差**（Offer MPC 21%–35%，同一计划按功率执行是 41%–50%）。固定价格的报价在价格刚越过门槛时就成交，在晚高峰爬坡时卖早了。环境支持报价，但会用报价的策略还没有。
- **改进的预测基线不稳定**：验证段从 50% 升到 60%（HB_WEST）、44% 升到 56%（HB_HOUSTON），测试段没有变化。
- **跨日**：每天午夜强制回到半满，上界损失 2%–5%；滚动优化类策略在 7 天连续回合里多赚 6%–31%。
- **电池时长**（HB_WEST 测试段，完美预见）：1、2、4 小时分别为每 MW 每天 194、312、442 美元；因果策略的捕获率随时长上升。
- **置信区间很宽**：50 多天的样本上，多数策略捕获率的 95% 区间宽 15–35 个百分点，相邻策略的区间大多重叠，排名不能当作结论。HB_WEST 测试段完美预见收益的 36% 来自最好的 5 天。
