# 发给云服务器项目的导出请求

请保留现有 v0.2 数据，并单独导出能量＋ECRS 最小验证需要的数据包。

1. `HB_WEST` 五分钟能量价格（LMP）和系统实时 ECRS MCPC。另附同一期间
   15 分钟能量 SPP，便于以后核对真正的结算价格。请写清每个字段的单位。
2. 保留实际 SCED 执行时间、原始时间戳、时区和有效区间。请注明时间戳
   表示执行时间、区间开始还是区间结束；不要把它们直接视为同一含义。
3. 如果有实际发布时间/入库时间，请一并保留；没有则明确写“不可得”。
   历史价格表的日期不应被当作它当时已经可见的证据。
4. 原始文件和处理后文件分别打包；缺失、重复、改价、异常间隔应有报告。
   请不要补零、插值或用最近时间戳匹配。若既有文件已经做过这些处理，
   请说明受影响字段、时间段和处理规则，保留可追溯标记。
5. 附 `manifest.json`：数据供应方和 dataset/report ID、下载时间、起止日期、
   hub/节点、列映射、软件版本、每个文件 SHA-256、已知价格修订情况。
6. 为后续留出验证，请标出哪些日期已经被用于调参、选择方法或检查结果。
   不要把这些日期重新命名为未使用的测试集。

先给一段价格完整的三到七天窗口及其前至少一天历史即可检验接口；完整
实验的时间窗将在数据审核后固定。原有 15 分钟能量价格不能替代五分钟
ECRS MCPC。请保留原文件，另存导出包。
